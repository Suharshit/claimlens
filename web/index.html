How it runs

Intake runs first. Policy Retrieval and Fraud Signal then run in parallel; Cost waits only for the policy limits; the Manager fans in and is the one place a verdict is made; escalations go to the Human Review Desk. Agents share one claim-state record and never import each other. All money maths is deterministic Python; the LLM only gives Intake a second reading of the claim, and the rules win any disagreement.
